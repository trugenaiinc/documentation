---
title: 'Get Presentation'
openapi: 'GET /ext/presentation/{id}'
---

Fetch a single presentation deck by its unique ID. Returns metadata, processing status, and resource preview links.

## Parameters

- `id` (path, required): unique identifier of the presentation deck

## Example

```bash
curl --request GET \
  --url https://api.trugen.ai/v1/ext/presentation/b3a3bc93-6b37-496e-989d-cf793792f428 \
  --header 'x-api-key: YOUR_API_KEY'
```
