Your API key is used to authenticate requests to the TruGen AI API. API keys can be created and managed from the [TruGen AI Dashboard](https://app.trugen.ai/).

### Create a New API Key

From the [API Keys page](https://app.trugen.ai/api-keys), click **Create API Key**.

<Note>
  The label is only used to help you identify the API key. It is not used for authentication.
</Note>

<img src="/images/create-api-key.png" alt="Create API Key" width="400" style={{ display: 'block', margin: '0 auto' }} />

Give your API key a name. Adding a description is optional.

Click **Create** to generate your API key. Make sure to copy and store it in a secure location, as you will not be able to view it again later.

<img src="/images/created-api-key.png" alt="Created API Key" width="400" style={{ display: 'block', margin: '0 auto' }} />

<Warning>
  API keys are securely encrypted and stored by TruGen AI. For security reasons, API keys cannot be recovered once lost. If you lose your API key, you will need to create a new one from the [TruGen AI Dashboard](https://app.trugen.ai/).
</Warning>
