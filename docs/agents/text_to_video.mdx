Turn a written script into a fully rendered avatar video in minutes. Provide your text, choose an avatar and voice, and TruGen handles the rest — lip sync, facial expression, and delivery are all generated automatically.

<Note>This is in private preview. If you'd like to try it, please contact us at [support@trugen.ai](mailto:support@trugen.ai).</Note>

## How It Works

<Steps>

  <Step title="Get an API Key">
    Generate an API key from the [TruGen Developer Portal](https://app.trugen.ai) and include it as the `x-api-key` header in every request.
  </Step>

  <Step title="Choose an Avatar">
    Pick an avatar ID from the [Avatar Gallery](/docs/avatars/gallery) and paste it into your payload.

    ```bash
    "avatar_id": "c5b563de"
    ```
  </Step>

  <Step title="Choose a Voice">
    Select a voice from the table below and include the `voice_id`, `provider_name`, and `model_name` in your payload.

    ```bash
    "provider_name": "elevenlabs",
    "model_name": "eleven_turbo_v2_5"
    ```
  </Step>

  <Step title="Write Your Script">
    Provide the text you want the avatar to speak. The avatar's lip movements and expressions are automatically synced to the generated audio.

    ```bash
    "script": "Hello, welcome to TruGen."
    ```
  </Step>

  <Step title="Set a Callback URL">
    Video generation is asynchronous. Provide a publicly reachable HTTPS endpoint — TruGen will POST the finished video link to it when rendering is complete.

    ```bash
    "callback_url": "https://yourdomain.com/webhook/video-ready"
    ```
  </Step>

  <Step title="Submit the Request">
    Send a `POST` to the video generation endpoint with your full payload.

    <CodeGroup>
    ```bash cURL
    curl --request POST \
      --url https://api.trugen.ai/v1/script-to-video/createVideo \
      --header 'Content-Type: application/json' \
      --header 'x-api-key: <your-api-key>' \
      --data '{
        "avatar_id": "c5b563de",
        "voice_id": "FGY2WhTYpPnrIDTdsKH5",
        "provider_name": "elevenlabs",
        "model_name": "eleven_turbo_v2_5",
        "script": "Hello, welcome to TruGen.",
        "callback_url": "https://yourdomain.com/webhook/video-ready"
      }'
    ```

    ```python Python
    import requests

    url = "https://api.trugen.ai/v1/script-to-video/createVideo"

    payload = {
        "avatar_id": "c5b563de",
        "voice_id": "FGY2WhTYpPnrIDTdsKH5",
        "provider_name": "elevenlabs",
        "model_name": "eleven_turbo_v2_5",
        "script": "Hello, welcome to TruGen.",
        "callback_url": "https://yourdomain.com/webhook/video-ready"
    }

    headers = {"x-api-key": "<your-api-key>"}

    response = requests.post(url, json=payload, headers=headers)
    print(response.json())
    ```
    </CodeGroup>

    <Note>Replace `<your-api-key>` with your actual API key from the [Developer Portal](https://app.trugen.ai).</Note>
  </Step>

</Steps>
