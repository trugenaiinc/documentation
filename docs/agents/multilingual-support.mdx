AI Teammates support conversations in a wide range of global languages. The speech pipeline is powered by **Deepgram** and **ElevenLabs** for high-accuracy transcription (STT), and **ElevenLabs** and **Cartesia** for lifelike voice synthesis (TTS) — both of which automatically adapt to the detected language when using `multi` mode.

## Setting the Language

Set the STT provider and language when creating an agent via API:

<CodeGroup>
```bash Create Agent with Language
curl --request POST \
  --url https://api.trugen.ai/v1/ext/agent \
  --header 'Content-Type: application/json' \
  --header 'x-api-key: YOUR_API_KEY' \
  --data @- <<EOF
{
  "agent_name": "Multilingual Agent",
  "config": { "timeout": 240 },
  "avatars": [
    {
      "config": {
        "llm": {
          "provider": "openai",
          "model": "gpt-4.1-mini"
        },
        "stt": { "provider": "deepgram", "model": "nova-3", "language": "multi" },
        "tts": { "provider": "elevenlabs", "voice_id": "ZUrEGyu8GFMwnHbvLhv2" }
      },
      "persona_name": "Multilingual Agent",
      "persona_prompt": "You are a helpful AI agent. Always respond in the same language the user speaks."
    }
  ]
}
EOF
```
</CodeGroup>

<Tip>When using `multi` mode, ElevenLabs and Cartesia TTS automatically adjust output to match the detected language — no extra configuration needed.</Tip>
