Every agent speaks through a **Text-to-Speech (TTS)** engine that converts the LLM's text response into audio in real time. TruGen supports industry-leading voice providers including **ElevenLabs**, **Cartesia**, **Rime**, **Fish Audio**, and **Inworld TTS** — delivering ultra-low first-audio latency across a wide range of voices, accents, and styles.

The voice is configured per agent via `voice_id`. Copy an ID from the [Voice Library](/docs/agents/voices/library) and drop it into your agent config.

## Setting a voice

Set `voice_id` when you create or update an agent. Everything else (provider, model, sample rate, encoding) falls back to platform defaults if omitted.

```json
{
  "agent_name": "Support Agent",
  "avatars": [
    {
      "avatar_key_id": "665a1170",
      "tts": {
        "voice_id": "FGY2WhTYpPnrIDTdsKH5"
      }
    }
  ]
}
```

<Note>You can also change the voice directly from the **Create New Agent** form in the [Developer Portal](https://app.trugen.ai): no code required.</Note>

## Full TTS configuration

For advanced use (custom pronunciations, sample rate, pitch, speaking rate, stability), pass a full `tts` object:

```json
"tts": {
  "provider": "elevenlabs",
  "model_id": "eleven_turbo_v2_5",
  "voice_id": "FGY2WhTYpPnrIDTdsKH5",
  "language": "a",
  "speaking_rate": 1.0,
  "stability": 0.5,
  "similarity_boost": 0.75,
  "sample_rate": 16000,
  "encoding": "pcm_s16le",
  "fallback_voice_id": "am_puck",
  "customPronounciation": [
    { "word": "TRUGEN", "pronounciation": "TRUE GEN" },
    { "word": "SQL",    "pronounciation": "Sequel" }
  ]
}
```

See the [full agent configuration reference](/api-reference/endpoint/agentcreate) for every field.

| Goal | Recommendation | Provider |
| --- | --- | --- |
| Professional, corporate tone | Chris, Will, Evan | ElevenLabs |
| Warm, conversational tone | Rachel, Laura, Hope | ElevenLabs |
| Streaming real-time conversations | Brooke, Blake, Katie | Cartesia |
| Enterprise-grade clarity | Luna, Celeste, Orion | Rime |

| Provider | Provider Key | Model | Best for |

## Custom pronunciations

Product names, acronyms, and industry jargon often get mispronounced. Fix them per-voice by adding entries to `customPronounciation`:

```json
"customPronounciation": [
  { "word": "TRUGEN",  "pronounciation": "TRUE GEN" },
  { "word": "API",     "pronounciation": "A P I" },
  { "word": "SQL",     "pronounciation": "Sequel" },
  { "word": "GraphQL", "pronounciation": "Graph Q L" }
]
```

Pronunciations apply to whichever voice is set on the agent. For dictionaries shared across many agents, see [pronunciation dictionaries](/docs/agents/voices/library#pronunciation-dictionaries) *(coming soon)*.

## Fallback voices

If the primary TTS provider fails or is rate-limited, TruGen falls back to a secondary voice automatically. Set `fallback_voice_id` to a voice from a different provider for resilience:

```json
"tts": {
  "provider": "elevenlabs",
  "voice_id": "FGY2WhTYpPnrIDTdsKH5",
  "fallback_voice_id": "am_puck"
}
```

## Voice cloning

For a fully custom voice (a spokesperson, a specific character, or your CEO), TruGen supports voice cloning through ElevenLabs Professional Voice Cloning. Contact [sales@trugen.ai](mailto:sales@trugen.ai) or provide an existing PVC voice ID directly as `voice_id`.
