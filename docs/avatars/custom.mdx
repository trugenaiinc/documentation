Custom avatars let you build agents with your own face, a customer's face, a spokesperson, or a designed character: all driven by TruGen's **Huma-3** neural rendering engine.

<Note>Custom avatars are currently in **Beta**.</Note>

## Create via API

You can also create a custom avatar programmatically by sending a `POST` request to the `/v2/custom-avatar` endpoint with the avatar details and a base64-encoded source image.

### Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `avatar_name` | string | yes | A human-readable name for your custom avatar. |
| `gender` | string | yes | Must be `"male"` or `"female"`. |
| `input_image` | string | yes | Source photo as a base64 data URI. Max ~12 MB base64 (~9 MB binary). |

<CodeGroup>

```javascript JavaScript
const myHeaders = new Headers();
myHeaders.append("x-api-key", "YOUR_API_KEY");
myHeaders.append("Content-Type", "application/json");

const raw = JSON.stringify({
  "avatar_name": "my_avatar",
  "gender": "male",
  "input_image": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAAAQABAAD..."
});

const requestOptions = {
  method: "POST",
  headers: myHeaders,
  body: raw,
  redirect: "follow"
};

fetch("https://api.trugen.ai/v2/custom-avatar", requestOptions)
  .then((response) => response.text())
  .then((result) => console.log(result))
  .catch((error) => console.error(error));
```

```python Python
import requests
import json

url = "https://api.trugen.ai/v2/custom-avatar"

payload = json.dumps({
  "avatar_name": "my_avatar",
  "gender": "male",
  "input_image": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAAAQABAAD..."
})
headers = {
  'x-api-key': 'YOUR_API_KEY',
  'Content-Type': 'application/json'
}

response = requests.request("POST", url, headers=headers, data=payload)

print(response.text)
```

</CodeGroup>

### Response

The API returns immediately with an initial job status while the avatar is generated in the background. Poll `GET /v2/custom-avatar/{id}` to watch progress until `status` becomes `COMPLETED`.

```json
{
  "id": "3b6f4c8a-...-...",
  "job_id": "sync-abcd-...",
  "avatar_key_id": "a1b2c3d4e5",
  "avatar_id": "a1b2c3d4e5",
  "avatar_name": "my_avatar",
  "gender": "male",
  "category": "trugen",
  "status": "QUEUED",
  "is_private": true
}
```

## When to use a Custom Avatar

- **Personal brand agents**: use your own face for a coach, tutor, or spokesperson agent.
- **Enterprise personas**: create a consistent brand character across all customer touch points.
- **Character-driven experiences**: build entertainment, storytelling, or roleplay agents with a designed persona.
- **Customer-facing sales agents**: use a photo of a real team member to make outreach feel personal.

## Using Your Custom Avatar

Once the job reaches `COMPLETED`, pass the `avatar_key_id` from the create response into the `avatars[0].avatar_key_id` field when creating an agent — the same shape used for stock avatars:

```json
{
  "agent_name": "My Custom Agent",
  "agent_system_prompt": "...",
  "avatars": [{ "avatar_key_id": "YOUR_AVATAR_KEY_ID" }]
}
```
