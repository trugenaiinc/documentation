This guide walks you through creating an AI Teammate via API and embedding it in your application. You'll need an API key from the [TruGen Developer Portal](https://app.trugen.ai) before you start.

<Steps>

  <Step title="Embed the Agent">
    You can embed your agent using either the React component or a plain iFrame.

    <Tabs>
      <Tab title="React">
        **Install**

        ```bash
        npm install @aiteammate/agent-widget
        ```

        **Usage**

        ```tsx
        import "@aiteammate/agent-widget/styles.css";
        import { TrugenAgentWidget } from "@aiteammate/agent-widget";

        export default function TrugenWidget() {
          return (
            <TrugenAgentWidget
              agentId="<agent-id>"
              userName="USER_NAME"
              userId="USER_ID"
              context="CONTEXT"
            />
          );
        }
        ```
      </Tab>

      <Tab title="iFrame">
        ```html
        <!DOCTYPE html>
        <html>
          <head>
            <title>Trugen AI</title>
            <meta name="viewport" content="width=device-width, initial-scale=1" />
            <style>
              html,
              body {
                width: 100%;
                height: 100%;
                margin: 0;
                overflow: hidden;
                background: #0f0f0f;
              }

              .trugen-fullscreen-widget {
                display: block;
                width: 100%;
                height: 100dvh;
                min-height: 220px;
                border: 0;
              }
            </style>
          </head>
          <body>
            <!-- Replace USER_NAME, USER_ID, and CONTEXT -->
            <iframe
              class="trugen-fullscreen-widget"
              src="https://app.trugen.ai/embed/<agent-id>?username=USER_NAME&id=USER_ID&context=CONTEXT"
              allow="camera; microphone; fullscreen; display-capture"
            >
            </iframe>
          </body>
        </html>
        ```
      </Tab>
    </Tabs>

    <Note>Replace `<agent-id>` with the `id` returned in Step 1, and substitute `USER_NAME`, `USER_ID`, and `CONTEXT` with values that identify the end user in your app.</Note>

    Your agent is now live — open the page in a browser and start a conversation.
  </Step>
