Give a face to your LiveKit agents with TruGen Avatars, using our official LiveKit Agents plugin.

<Tabs>
  <Tab title="Python">
    <Steps>
      <Step title="Install the plugin">
        Install the TruGen plugin from the LiveKit registry:
        ```bash
        uv add "livekit-agents[trugen]~=1.3" # When using UV
        ```
        ```bash
        pip install "livekit-agents[trugen]~=1.3" # When using PIP
        ```
      </Step>
      <Step title="Generate an API key">
        1. Using the TruGen [Developer Platform](https://app.trugen.ai), generate an API key from the developers page.
        2. Set the newly generated API key as `TRUGEN_API_KEY` environment variable in your `.env` file.
      </Step>
      <Step title="Add Avatar session to your LiveKit Agent">
        1. Import the `trugen` plugin from `livekit.plugins`:
        ```python
        from livekit.plugins import trugen
        ```
        2. Instantiate a new `AvatarSession` and set the avatar ID:
        ```python
        avatar_id = os.getenv("TRUGEN_AVATAR_ID") or "45e3f732"
        trugen_avatar = trugen.AvatarSession(avatar_id=avatar_id)
        ```
        3. Start the avatar session, passing the current agent session and room context:
        ```python
        await trugen_avatar.start(session, room=ctx.room)
        ```

        #### Complete Example

        <CodeGroup>
        ```python Python highlight={1-2,8-10}
        from livekit.plugins import trugen

        async def entrypoint(ctx: JobContext):
            session = AgentSession(
              # Your existing configuration
            )

            avatar_id = os.getenv("TRUGEN_AVATAR_ID") or "45e3f732"
            trugen_avatar = trugen.AvatarSession(avatar_id=avatar_id)
            await trugen_avatar.start(session, room=ctx.room)

            await session.start(
              # Start agent session as usual
            )
        ```
        </CodeGroup>

        4. To gracefully shut down, use `ctx.room.disconnect()` to close the room connection or `ctx.shutdown()` to end the `JobContext`.

        <Tip>TruGen automatically stops the session when the room is disconnected or the primary participant disconnects.</Tip>
      </Step>
    </Steps>
  </Tab>

  <Tab title="JavaScript">
    <Steps>
      <Step title="Install the plugin">
        ```bash npm
        npm install @livekit/agents-plugin-trugen
        ```
        ```bash pnpm
        pnpm add @livekit/agents-plugin-trugen
        ```
      </Step>
      <Step title="Set up environment variables">
        Add the following to your `.env` file:
        ```ini .env
        TRUGEN_API_KEY=your-trugen-api-key
        TRUGEN_AVATAR_ID=your-avatar-id

        LIVEKIT_URL=your-livekit-url
        LIVEKIT_API_KEY=your-livekit-api-key
        LIVEKIT_API_SECRET=your-livekit-api-secret
        ```
      </Step>
      <Step title="Add Avatar session to your LiveKit Agent">
        <CodeGroup>
        ```typescript TypeScript
        import { AvatarSession } from '@livekit/agents-plugin-trugen';

        const avatarSession = new AvatarSession({
          avatarId: process.env.TRUGEN_AVATAR_ID,
          apiKey: process.env.TRUGEN_API_KEY,
        });

        await avatarSession.start(agentSession, room, {
          livekitUrl: process.env.LIVEKIT_URL,
          livekitApiKey: process.env.LIVEKIT_API_KEY,
          livekitApiSecret: process.env.LIVEKIT_API_SECRET,
        });
        ```
        ```javascript JavaScript
        import { AvatarSession } from '@livekit/agents-plugin-trugen';

        const avatarSession = new AvatarSession({
          avatarId: process.env.TRUGEN_AVATAR_ID,
          apiKey: process.env.TRUGEN_API_KEY,
        });

        await avatarSession.start(agentSession, room, {
          livekitUrl: process.env.LIVEKIT_URL,
          livekitApiKey: process.env.LIVEKIT_API_KEY,
          livekitApiSecret: process.env.LIVEKIT_API_SECRET,
        });
        ```
        </CodeGroup>

        | Option | Required | Default | Description |
        | --- | --- | --- | --- |
        | `apiKey` | Yes |: | Your TruGen API key |
        | `avatarId` | No | Stock avatar | The avatar ID to use |
        | `apiUrl` | No | `https://api.trugen.ai` | TruGen API base URL |
        | `avatarParticipantIdentity` | No | `trugen-avatar` | LiveKit participant identity |
        | `avatarParticipantName` | No | `Trugen Avatar` | Display name in the room |
        | `connOptions` | No |: | Connection retry configuration |
      </Step>
    </Steps>
  </Tab>
</Tabs>
