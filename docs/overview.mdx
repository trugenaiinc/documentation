**TruGen is a platform for building real-time AI video teammates**: agents that hold live, face-to-face conversations with your users through a photorealistic avatar. A teammate sees the user through their camera, hears them through their microphone, and answers with lip-synced speech in under a second: grounded in your data, wired to your tools, and speaking whichever of 60+ languages the user chose.

Underneath: TruGen's proprietary **Huma** avatar renderer, the **Hawkeye** vision model, a fully pluggable **STT → LLM → TTS** pipeline, and enterprise-ready primitives for auth, sessions, and compliance. Ship with a single iFrame, a drop-in React widget, or the JavaScript / Python SDK: every path runs on the same infrastructure underneath.

## How it works

Every agent runs through the same five-stage pipeline. Each stage is pluggable, and every stage can be configured per agent.

<Steps>
  <Step title="Capture: WebRTC in">
    The user's audio and video stream into the pipeline with sub-100 ms
    transport, from any modern browser or mobile web.
  </Step>
  <Step title="Perceive: STT + Hawkeye-1">
    Speech-to-text transcribes audio in real time. Hawkeye-1 analyses the video
    stream for gaze, gesture, and scene context: and hands both to the LLM.
  </Step>
  <Step title="Reason: LLM">
    The language model generates a response using the agent's system prompt,
    attached knowledge base, memory, and available tools.
  </Step>
  <Step title="Speak: TTS">
    Text-to-speech renders the response as natural, expressive audio in the
    language the user spoke.
  </Step>
  <Step title="Render: Huma-2 + WebRTC out">
    Huma-2 generates the avatar video frame-by-frame, synced to the audio, and
    streams both back to the user: closing the loop in under a second.
  </Step>
</Steps>

## Performance characteristics

| Metric                               | Value                                                       |
| ------------------------------------ | ----------------------------------------------------------- |
| End-to-end response latency (Huma-2) | ≤ 800 ms typical                                            |
| Huma-2 render pipeline               | ≤ 500 ms (audio in → video out)                             |
| Concurrent sessions                  | Scale-based; contact sales for high-concurrency plans       |
| Uptime target                        | 99.9%                                                       |
| Supported languages                  | 60+ (see [multilingual](/docs/agents/multilingual-support)) |

Numbers are measured on the default Groq + ElevenLabs stack. Latency and quality vary with your chosen LLM, TTS, and network path.

## Foundation models

TruGen ships three proprietary models. Each has a specific job: combine them or use them independently.

| Model         | Role                                | Notes                                                                                            |
| ------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------ |
| **Huma-2**    | Real-time avatar renderer           | Gaussian-splatting based. Trainable from 2–3 min of source video. ≤ 500 ms render pipeline.      |
| **Huma-1**    | Expressive avatar renderer (legacy) | Higher expressiveness at slightly higher latency. Recommended for pre-recorded video generation. |
| **Hawkeye-1** | Vision action recognition           | Continuous scene, gaze, gesture, and multi-face analysis fed into the LLM as context.            |

[Compare models in depth →](/docs/models/overview)
